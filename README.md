Mini TP 3
**Mini-TP 3 (gRPC vs REST):** por llamada gRPC fue 1.2x–1.3x más rápido, porque domina la inferencia del Random Forest (≈11 ms); su overhead de protocolo fue 4x–5x menor que el de REST (0.7 ms contra 3.0–3.7 ms), el request pesó 48 B contra 216 B, y un lote de 63 casos por streaming fue 31x más rápido que 63 llamadas REST.
